A studio catalogue photograph of an impossible gadget: the TOAST-AIR 3000, a chrome toaster whose slice of toast never lands hard — it pops up and floats back down under a small red-and-white parachute. The parachute is the gadget's one accessory; the toast, the toaster and the parachute are the whole picture.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024×1024 PNG). The program uses only the Python standard library and Pillow, draws everything itself with no network, and is fully deterministic — two runs produce byte-identical output.
